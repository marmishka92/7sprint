• conftest.py: Фикстуры и вспомогательные функции.
• endpoints.py: Определения эндпоинтов API.
• helpers.py: Вспомогательные функции для тестирования.
• urls.py: Базовые URL API.
• tests/: Директория, содержащая тесты:
  • test_create_courier.py: Тесты для создания курьера.
  • test_login_courier.py: Тесты для логина курьера.
  • test_create_order.py: Тесты для создания заказа.
  • test_order_list.py: Тесты для получения списка заказов.
• requirements.txt: Список зависимостей проекта.
